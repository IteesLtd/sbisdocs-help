# Единицы измерения в УПД

У каждой строки УПД может быть единица измерения — код по ОКЕИ и название, например 796 «шт». Во вкладке «Единица измерения в УПД» в «Настройках» выберите, откуда приложение берёт единицы.

![Вкладка «Единица измерения в УПД»]({{ "/assets/img/tab-units.png" | relative_url }})

## Из CRM

У каждой строки УПД — единица строки товара в сделке, как она есть.

Строке, где у товара в каталоге не указана единица, и строке без товара каталога (позиция вписана в сделку вручную) Битрикс24 сам ставит единицу портала по умолчанию — обычно «шт». Если задана «Единица для строк без единицы», такая строка получит её. Единицу, которую в строке сделки выбрали вручную, приложение не меняет.

## Из настроек приложения

Единицы CRM не читаются. Вместо них — таблица «Единицы для товаров каталога»: «Добавить строку», выберите товар каталога и укажите код по ОКЕИ (3–4 цифры) и название. Строка УПД с этим товаром получит единицу из таблицы.

Товара нет в таблице или позиция вписана в сделку вручную — строка получает «Единицу для строк без единицы».

## Единица для строк без единицы

- «Без единицы» — строка уйдёт в УПД без кода и названия единицы, формат ФНС это допускает. Подходит для услуг.
- «Указать единицу» — код по ОКЕИ и название, например 876 «усл. ед.».

Нажмите «Сохранить». Настройка применяется к документам, которые ещё не ушли в Saby.

Справочник единиц портала и товары CRM приложение не меняет.
