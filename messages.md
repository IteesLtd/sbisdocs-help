# Сообщения и ошибки

Все тексты, которые показывает приложение, и что с ними делать. «…» в тексте — место, куда приложение подставляет номер, название поля или ответ Saby.

## Данные сделки

Документ получает статус «Ошибка в данных сделки», в строке — перечень. Исправьте сделку или реквизиты и нажмите «Проверить снова».

| Текст | Что сделать |
| --- | --- |
| «В сделке не выбрана ваша компания» | Выберите в сделке «Реквизиты вашей компании» |
| «В сделке нет товаров» | Добавьте товары в сделку |
| «Валюта сделки …: УПД формируется только в рублях» | Переведите сделку в рубли |
| «Нет названия продавца» / «…покупателя» | Заполните название в реквизитах |
| «Нет ИНН …», «ИНН … — нужно 10 цифр у организации или 12 у ИП» | Заполните или исправьте ИНН |
| «Нет КПП …», «КПП … — нужно 9 символов» | Заполните или исправьте КПП (нужен только организации) |
| «Нет адреса …» | Заполните адрес в реквизитах (нужен для СЧФДОП) |
| «БИК банка … — нужно 9 цифр» | Исправьте БИК |
| «Нет ФИО руководителя продавца — он указывается подписантом УПД» | Заполните руководителя в реквизитах вашей компании |
| «Нет ФИО индивидуального предпринимателя продавца» / «…покупателя» | Заполните ФИО в реквизитах ИП |
| «У строки … нет названия» | Заполните название товара в строке |
| «У строки «…» нулевое количество» / «отрицательное количество» | Исправьте количество |
| «У строки «…» нулевая цена» / «отрицательная цена» / «отрицательная сумма» | Исправьте цену или скидку |
| «У строки «…» нет названия единицы измерения» | Укажите название единицы — «[Единицы измерения в УПД](../units/)» |
| «… ставка НДС … % — в УПД такой нет» | Выберите ставку, которая бывает в УПД, или «без НДС» |
| «… код единицы «…» не по ОКЕИ (3–4 цифры)» | Исправьте единицу измерения — «[Единицы измерения в УПД](../units/)» |
| «В сделке не заполнено поле с датой документа «…»» | Заполните поле даты в сделке |
| «Не выбрано поле сделки с датой документа», «Не выбрано поле сделки с номером документа» | Выберите поле в окне настроек робота |
| «Шаблон номера «…» должен содержать ровно одну метку {N}», «…должен быть не длиннее … символов» | Исправьте шаблон в окне настроек робота |
| «Поле номера указано неверно: «…» — ожидается пользовательское поле сделки UF_CRM_…» | Выберите поле номера в окне настроек робота заново |

## Номер документа

| Текст | Что сделать |
| --- | --- |
| «Не заполнен ИНН вашей компании — номер не выдан, заполните реквизиты и нажмите «Проверить снова»» | Заполните ИНН в реквизитах вашей компании |
| «СБИС не ответил при поиске последнего номера — нажмите «Проверить снова»» | Повторите через несколько минут |
| «Не заполнено поле сделки … с номером документа» | Заполните поле номера в сделке |
| «Номер из поля сделки … длиннее 64 символов» | Сократите номер в поле сделки |
| «Номер … уже занят документом от …» | Номер уже у другого документа вашей компании — поменяйте его |
| «Нет номера документа» | Задайте номер — «[Как поправить номер или дату](../edit/)» |

При правке номера и даты карандашом: «Такой номер уже есть у другого документа вашей компании», «Номер берётся из поля сделки — измените его в сделке», «Дата берётся из сделки — измените её в сделке», «Документ уже ушёл контрагенту или его правили в СБИС — изменить нельзя», «Проверьте введённые значения» — подробно в статье «[Как поправить номер или дату](../edit/)».

## Журнал робота

Робот пишет результат в журнал бизнес-процесса сделки; в начале строки — название документа «УПД № … от …».

| Текст | Что значит |
| --- | --- |
| «… создан и будет передан в СБИС», «… обновлён и будет передан в СБИС» | Всё в порядке |
| «… создан; СБИС не подключён — документ уйдёт после подключения», «… обновлён; СБИС не подключён…» | Подключите Saby в «Настройках» |
| «… создан с ошибкой и не уйдёт в СБИС: …», «… обновлён с ошибкой…» | Документ создан. Не хватает данных — исправьте сделку и «Проверить снова». Если после двоеточия «Не удалось создать элемент хранилища: …» — нажмите у документа «Отправить в СБИС», обмен создаст элемент |
| «УПД № … уже в СБИС — изменения вносите там» | Документ в Saby, сделка не менялась |
| «…: Сделка изменилась — черновик в СБИС не обновлён, нажмите «Обновить из сделки»», «…: Сделка изменилась после отправки — исправьте документ в СБИС» | См. «[Как отправить исправленный документ в СБИС](../resend/)» |
| «…: Сделку не прочитать: она удалена или недоступна.» | Документ уже в Saby, а сделку робот прочитать не смог — проверьте сделку |
| «…: Документ обновляется параллельно — нажмите «Проверить снова»» | Нажмите «Проверить снова» у документа |
| «Не удалось прочитать сделку: …» | Документ не создан — проверьте сделку и запустите робота снова |
| «Хранилище не настроено: выберите смарт-процесс документов в настройках приложения «Документы СБИС».» | Пройдите мастер установки |
| «Не удалось сформировать УПД: …» | Сбой при работе робота — запустите его снова: если документ уже есть, робот обновит тот же. Повторится — напишите в [поддержку](../support/) |

## Лента сделки

По исходящим документам приложение пишет комментарии в ленту сделки (одинаковые сообщения об обмене подряд не повторяются; «УПД не сформирован…» и ошибки данных пишутся при каждом запуске робота):

- «…: сформирован роботом», «…: обновлён роботом по сделке»;
- «…: черновик записан в СБИС», «…: черновик обновлён в СБИС»;
- «…: в СБИС — <статус в Saby>»;
- «…: черновик правили в СБИС — сверьте вручную»;
- «…: черновик удалён в СБИС», «…: удалён в СБИС»;
- «…: ошибка обмена — …», «… не отправлен в СБИС: …. Подробности — в приложении «Документы СБИС».»;
- «…: Сделка изменилась — …» (два варианта, как в списке);
- «УПД не сформирован: в приложении «Документы СБИС» не выбран смарт-процесс для документов. Администратору — выбрать его в настройках приложения и запустить робота снова.»

## Ошибки обмена в строке документа

Если в строке есть «Повтор автоматически в …», приложение повторит само; если нет — после исправления нажмите «Отправить в СБИС».

| Текст | Что сделать |
| --- | --- |
| «СБИС: …» | Ответ Saby — исправьте то, о чём в нём сказано |
| «СБИС: не найден участник ЭДО с ИНН …» | Контрагент не подключён к ЭДО или ИНН неверный. Автоповтора нет |
| «СБИС: нет ИНН вашей организации в подключении — переподключите СБИС в настройках.» | Переподключите Saby во вкладке «Подключение к СБИС». Автоповтора нет |
| «Вызов метода … заблокирован согласно назначенным правам» | Не хватает прав в Saby — «[Права приложения в Saby](../saby/)» |
| «СБИС не вернул состояние документа, запись черновика отложена.», «СБИС не вернул идентификатор документа.» | Сбой Saby |
| «Не удалось создать элемент хранилища: …» | Элемент смарт-процесса не создался; от робота — автоповтора нет |
| «СБИС не отдал файлы документа: …» | У входящего не скачались файлы |
| «XML не записан в элемент: …», «Статус СБИС не записан в элемент: …», «Товары не записаны в элемент: …» | Обмен трижды подряд не смог дописать элемент и больше не пытается; статус документа не меняется. Проверьте, не удалён ли элемент и есть ли у приложения права на смарт-процесс, и напишите в [поддержку](../support/) |

| --- | --- |
| «Не получилось. Попробуйте ещё раз» | «Отправить в СБИС», «Проверить снова», «Создать заново» или «Обновить из сделки» не сработали — обновите список и повторите |

| «Документ удалён в СБИС — создайте его заново» | При правке карандашом: документ удалён в Saby — нажмите «Создать в СБИС» |
| «Документ не удалён в СБИС — создавать заново не нужно» | Документ в Saby на месте |
| «Не удалось загрузить данные» | Список не загрузился — нажмите «Повторить» |
| «Проверьте значения фильтра», «Проверьте значение» | В полях фильтра неверное значение |
