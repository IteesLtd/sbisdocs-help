# Сообщения и ошибки

Все тексты, которые показывает приложение, и что с ними делать. «…» в тексте — место, куда приложение подставляет номер, название поля или ответ Saby.

## Данные сделки

Документ получает статус «Ошибка в данных сделки», в строке — перечень. Исправьте сделку или реквизиты и нажмите «Проверить снова».

| Текст | Что сделать |
| --- | --- |
| «В сделке не выбрана ваша компания» | Выберите в сделке «Реквизиты вашей компании» |
| «В сделке нет товаров» | Добавьте товары в сделку |
| «Валюта сделки …: УПД формируется только в рублях» | Переведите сделку в рубли |
| «Нет названия продавца» / «…покупателя» | Заполните название в реквизитах |
| «Нет ИНН …», «ИНН … — нужно 10 цифр у организации или 12 у ИП» | Заполните или исправьте ИНН |
| «Нет КПП …», «КПП … — нужно 9 символов» | Заполните или исправьте КПП (нужен только организации) |
| «Нет адреса …» | Заполните адрес в реквизитах (нужен для СЧФДОП) |
| «БИК банка … — нужно 9 цифр» | Исправьте БИК |
| «Нет ФИО руководителя продавца — он указывается подписантом УПД» | Заполните руководителя в реквизитах вашей компании |
| «Нет ФИО индивидуального предпринимателя продавца» / «…покупателя» | Заполните ФИО в реквизитах ИП |
| «У строки … нет названия» и другие тексты «У строки «…» …» | Исправьте строку товара: название, количество, цену, ставку НДС |
| «… ставка НДС … % — в УПД такой нет» | Выберите ставку, которая бывает в УПД, или «без НДС» |
| «… код единицы «…» не по ОКЕИ (3–4 цифры)» | Исправьте единицу измерения — «[Единицы измерения в УПД](../units/)» |
| «В сделке не заполнено поле с датой документа «…»» | Заполните поле даты в сделке |

## Номер документа

| Текст | Что сделать |
| --- | --- |
| «Не заполнен ИНН вашей компании — номер не выдан, заполните реквизиты и нажмите «Проверить снова»» | Заполните ИНН в реквизитах вашей компании |
| «СБИС не ответил при поиске последнего номера — нажмите «Проверить снова»» | Повторите через несколько минут |
| «Не заполнено поле сделки … с номером документа» | Заполните поле номера в сделке |
| «Номер из поля сделки … длиннее 64 символов» | Сократите номер в поле сделки |
| «Номер … уже занят документом от …» | Номер уже у другого документа вашей компании — поменяйте его |
| «Нет номера документа» | Задайте номер — «[Как поправить номер или дату](../edit/)» |

При правке номера и даты карандашом: «Такой номер уже есть у другого документа вашей компании», «Номер берётся из поля сделки — измените его в сделке», «Дата берётся из сделки — измените её в сделке», «Документ уже ушёл контрагенту или его правили в СБИС — изменить нельзя», «Проверьте введённые значения» — подробно в статье «[Как поправить номер или дату](../edit/)».

## Журнал робота

Робот пишет результат в журнал бизнес-процесса сделки:

- «УПД создан и будет передан в СБИС» / «УПД обновлён и будет передан в СБИС» — всё в порядке;
- «УПД создан; СБИС не подключён — документ уйдёт после подключения» — подключите Saby в «Настройках»;
- «УПД создан с ошибкой и не уйдёт в СБИС: …» — исправьте сделку и нажмите «Проверить снова» у документа;
- «УПД № … уже в СБИС — изменения вносите там» — документ уже в Saby, см. «[Как отправить исправленный документ в СБИС](../resend/)»;
- «Не удалось прочитать сделку: …», «Сделку не прочитать: она удалена или недоступна.» — документ не создан; проверьте сделку и запустите робота снова;
- «Хранилище не настроено: выберите смарт-процесс документов в настройках приложения «Документы СБИС».» — пройдите мастер установки;
- «Не удалось создать элемент хранилища: …», «Не удалось сформировать УПД: …» — запустите робота снова; если повторится — напишите в [поддержку](../support/).

## Кнопки у документа

| Текст | Что значит |
| --- | --- |
| «Документ в этом состоянии нельзя отправить снова» | Документ уже ушёл дальше — обновите список |
| «Документ уже не черновик — обновить из сделки нельзя» | Черновик отправлен контрагенту — исправляйте в Saby |
| «Документ удалён в СБИС — создайте его заново» | Нажмите «Создать в СБИС» |
| «Документ не удалён в СБИС — создавать заново не нужно» | Документ в Saby на месте |
| «Документ не найден» | Документ удалён — обновите список |
| «Черновик правили в СБИС — сверьте вручную» | См. «[Как отправить исправленный документ в СБИС](../resend/)», раздел «Черновик правили в Saby» |
| «СБИС не отдал файлы документа: …» | При «Создать заново» у входящего — повторите позже |
| «Не получилось. Попробуйте ещё раз», «Не удалось загрузить данные» | Повторите действие |
| «Проверьте значения фильтра» | В полях фильтра неверное значение |

## Настройки и мастер

| Текст | Что значит |
| --- | --- |
| «Сначала выберите смарт-процесс для документов» | Пройдите шаг «Смарт-процесс» |
| «Сначала подключите СБИС» | Действие требует подключения к Saby |
| «Хранилище уже выбрано, сменить его нельзя» | Смарт-процесс выбирается один раз |
| «Не удалось создать смарт-процесс … Можно выбрать существующий смарт-процесс.» | Например, на тарифе кончился лимит смарт-процессов — подключите существующий |
| «Такой номер уже выдан», «№ … уже выдан: следующий номер — не меньше …» | Следующий номер серии не может быть ниже выданного |
| «Нужна ровно одна метка {N}, шаблон — не длиннее 50 символов» | Исправьте шаблон номера |
| «У компании нет ИНН в реквизитах — заполните его в CRM» | Заполните ИНН вашей компании |
| «В СБИС нет вашей организации с такими ИНН и КПП — или у подключения к Saby нет к ней прав. Укажите следующий номер вручную» | Проверьте реквизиты и права в Saby или задайте номер сами |
| «СБИС отказал: …» | Ответ Saby — исправьте то, о чём в нём сказано |
| «Выберите товар», «3–4 цифры», «От 1 до 255 символов» | Ошибки в таблице единиц |
| «Выберите поле, иначе роботу неоткуда взять дату / номер», «Поле не найдено, выберите заново» | В окне настроек робота |
| «Не удалось загрузить настройки. Закройте окно и откройте снова.», «Не удалось передать значения форме робота. Закройте окно и откройте снова.» | Окно настроек робота — откройте заново |
