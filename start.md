# С чего начать

Настраивает приложение администратор портала. Первый раз его встречает мастер установки: пока мастер не пройден, вместо списка документов показывается он, а кнопка «Настройки» справа вверху неактивна. Сотрудник, который не администратор, до этого видит «Приложение ещё не настроено — обратитесь к администратору».

## Шаги мастера

Между шагами — «Далее» и «Назад».

1. «СБИС» — ID приложения и защищённый ключ из кабинета Saby, файл сервисного ключа (.key), скачанный там же, и «Сохранить и проверить». Как получить ключи, расписано на самом шаге; какие права дать — в статье «[Права приложения в Saby](../saby/)». Пароль от кабинета не нужен. Пока СБИС не подключён, кнопка «Далее» называется «Подключить позже» — подключить можно и потом, в «Настройках».

2. «Смарт-процесс» — где хранить документы: «Создать новый смарт-процесс» (приложение создаст «Документы ЭДО» со всеми полями и связью со сделками) или «Подключить существующий» (приложение добавит в него свои поля, ваши поля и элементы не тронет). Выбор делается один раз, сменить его потом нельзя. Без смарт-процесса мастер не завершить.

3. «Нумерация» — как робот нумерует УПД: «Автоматически по шаблону» или «Из поля сделки» (для этого режима есть кнопка «Создать поле сделки»). В режиме по шаблону ниже показаны «Серии номеров ваших компаний» — по строке на каждую компанию из «Моих компаний» CRM (если их нет — «Заполните «Мои компании» в CRM»; показываются первые 50). Следующий номер можно задать вручную. «Взять последний номер из СБИС» ищет последний номер по шаблону в Saby за последний год и подставляет следующий; кнопка только читает, ничего не создаёт. Это значения по умолчанию — робот в воронке может их переопределить.

4. «Входящие» — включите приём входящих документов из Saby и привязку к компаниям CRM; подробнее — «[Как приходят входящие документы](../incoming/)».

5. «Единицы измерения» — откуда брать единицы для строк УПД; подробнее — «[Единицы измерения в УПД](../units/)».

6. «Робот» — «Открыть настройку роботов» у нужной воронки и поставьте на стадию, где нужен УПД, робота «Сформировать УПД в СБИС» из раздела приложений. Есть ссылка «Справка Битрикс24 по роботам».

Нажмите «Готово» — появится «Всё готово», откроется список документов.

Если СБИС не подключён на шаге «Нумерация», мастер пишет «Номера в СБИС не проверены — подключите СБИС до первого документа». Подключите Saby до первого запуска робота: иначе серия начнётся с 1, а не продолжит номера, которые уже есть в Saby.
{: .warning }

Мастер можно пройти заново: «Настройки» → вкладка «Мастер установки» → «Пройти мастер заново». Сохранённые настройки, серии номеров и смарт-процесс при этом не меняются.
