# С чего начать

Настраивает приложение администратор портала: кнопка «Настройки» справа вверху видна всем, но открыть настройки может только администратор портала.

Первый раз администратора встречает мастер установки: пока он не пройден, вместо списка документов показывается он. Шаги:

1. «СБИС» — ID приложения и защищённый ключ из кабинета Saby, файл сервисного ключа, скачанный там же, и «Сохранить и проверить». Как получить ключи, там же расписано по шагам. Пароль от кабинета не нужен. СБИС можно подключить позже кнопкой «Подключить позже».

2. «Хранилище» — где хранить документы: новый смарт-процесс или существующий. Выбор делается один раз, потом в «Настройках» видно, какой смарт-процесс подключён, но сменить его нельзя. Без хранилища мастер не завершить.

3. «Нумерация» — шаблон номера и следующий номер для каждой вашей компании. Кнопка «Взять последний номер из СБИС» подсказывает номер по последнему документу в Saby: она только читает, ничего не создаёт.

4. «Входящие» — включите приём входящих документов из Saby и привязку к компаниям CRM.

5. «Единицы» — единицы измерения в УПД: из CRM или из таблицы приложения. «Единица для строк без единицы» работает в обоих режимах: в режиме «Из CRM» её получает строка без товара или товара, у которого в каталоге не указана единица, — если в строке осталась единица, которую Битрикс24 ставит сам; единицу, выбранную в строке сделки вручную, приложение не меняет.

6. «Робот» — в воронке сделок откройте «Роботы» и поставьте на нужную стадию робота «Сформировать УПД в СБИС»; ссылки на роботы каждой воронки есть в мастере.

Нажмите «Готово». Мастер можно пройти заново: «Настройки» → вкладка «Мастер установки» → «Пройти мастер заново»; сохранённые настройки при этом не меняются.
